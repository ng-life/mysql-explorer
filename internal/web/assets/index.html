MCP 接入配置 · Streamable HTTP

在 MCP 客户端选择「Streamable HTTP」，填写下面的服务地址。MCP 随 serve 一同启动，与网页共用端口，无需独立进程；不使用旧版 /sse 地址。


      
上方为常见 mcpServers 格式示例，配置字段以客户端要求为准。远程访问时使用服务器地址，并确保 listen 绑定到可达地址；本机地址 127.0.0.1 只适用于同一台电脑。

      
可用工具：list_connections、list_schemas、list_tables、describe_table、execute_sql、get_metadata、refresh_metadata。execute_sql 的 mode 支持 query、explain、explain_analyze。

      
三端共用连接权限：type 决定数据库兼容模式，allow_dml、allow_ddl 控制写入。EXPLAIN ANALYZE 会实际执行 SELECT；写入失败后先核对状态，不要自动重试。服务无内置登录，远程接入应配置认证代理或网络访问控制。
